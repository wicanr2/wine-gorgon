# 座標換算：WinG DIB 的 (dx,dy) 落在螢幕 (dx-1, dy+39)，那是 client 區的原點
# （量法：把 DIB 的一整列拿去螢幕圖裡找）。主選單三格在 DIB 上的中線是
# NEW GAME y=188、LOAD GAME y=212、LISTEN TO MUSIC y=236，框寬 x 256..423。

# 遊戲迴圈另外用 GetCursorPos ＋ 那個 bit 取樣（RE:cseg11:0x94ee）。
# click 的按下與放開落在同一次訊息泵裡，那個 bit 還沒被讀到就被清掉了。
